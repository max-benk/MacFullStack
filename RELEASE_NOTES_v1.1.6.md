# MacFullStack 1.1.6 (build 116)

**Download:** `MacFullStack-1.1.6-arm64.dmg` (Apple Silicon, macOS 14+)

## What's new

### Project Studio (Pro)

A new **Studio** section in the sidebar — an in-app project workspace:

- project list, file tree, and tabbed editor
- syntax highlighting (PHP, JS/TS, Blade, JSON, `.env`, and more)
- line numbers, current-line highlight, status bar
- find & replace (⌘F), go to line (⌘L), duplicate line (⌘D)
- Tab / Shift+Tab indentation, font size and word-wrap toggles
- bottom dock: logs, terminal, `.env` editor
- quick actions: browser, external IDE, Log Hub, Finder

Free: section is locked with a Pro upgrade CTA.

### Editor & UX

- compact Studio toolbar aligned with SQL console and Terminal
- cursor position and open tabs persist between sessions
- tab context menu: close / close others / close all

## Improvements

- more reliable editor layout when toggling line numbers
- native undo/redo stays in sync with the toolbar
- English and German strings for new Studio UI

## Requirements

macOS 14+, Apple Silicon (arm64). Native mode does not require Docker.
